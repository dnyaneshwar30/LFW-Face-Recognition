# LFW Face Recognition using Machine Learning

## About the Project

I developed this face recognition project as part of my learning in Machine Learning and Deep Learning.

In this project, I worked with the Labeled Faces in the Wild (LFW) dataset to build a face classification model using Python and TensorFlow.

I used MobileNetV2 transfer learning to train the model and classify facial images into different person categories.

## Project Notebook

[Open Face Recognition Notebook](face_recognition.ipynb)

## Technologies Used

- Python
- TensorFlow and Keras
- MobileNetV2
- OpenCV
- NumPy
- Matplotlib
- Google Colab
- LFW Dataset

## What I Did

- Downloaded and prepared the LFW face dataset using Kaggle.
- Loaded facial images and organized them into different person categories.
- Resized images to 224 × 224 pixels and prepared them for model training.
- Split the dataset into training and testing sets.
- Used MobileNetV2 with transfer learning for face classification.
- Trained the model using TensorFlow and Keras.
- Evaluated the trained model using test data.
- Visualized training and validation accuracy.

## Dataset

I used the Labeled Faces in the Wild (LFW) dataset containing facial images of different people.

The dataset was downloaded through Kaggle in Google Colab.

## How to Run

1. Open the project notebook.
2. Run it using Google Colab.
3. Upload your Kaggle API credentials when requested.
4. Download and extract the LFW dataset.
5. Execute the notebook cells in order.
6. Train and evaluate the face classification model.
